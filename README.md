# Personal Assistant App

This simple application is interactive and built with Python.

# About

This app assists users with managing to-do lists and recording birthdays and contacts.

The Personal Assistant app is designed for a user to easily view, add, or remove to-do items, birthdays, or contacts.

# Project Background

The Personal Assistant app is a project designed by Skillcrush and is part of the "Getting Started with Python" class. The skills taught within this class include control structures, functions, classes, loops, modules and more that were used to create the Personal Assisant app. The app has two python files that work together and utilize JSON files to access and store data.
